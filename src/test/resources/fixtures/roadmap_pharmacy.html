기초 실무 실습

기초 약무 실무실습

  • 시기 : 5학년 1학기 (학기중)
  • 시간 : 총 60시간
  • 장소 : 본교 약학대학 실습약국

필수 실무 실습

병원 실무실습 1,2

  • 시기 : 5학년 2학기 (학기중)
  • 시간 : 총 400시간
  • 장소 : 서울성모병원 약제부

지역약국 실무실습

  • 시기 : 6학년 1학기 (학기중)
  • 시간 : 총 200시간
  • 장소 : 부천시약사회 소속 16개 약국

제약 실무실습

  • 시기 : 6학년 1학기 (겨울방학, 학기중)
  • 시간 : 총 120시간
  • 장소 : 서울대학교 제약 실습공장

약무 행정실무실습

  • 시기 : 6학년 1학기 (학기중)
  • 시간 : 총 20시간
